# Устройство слоёв — извод vue-spa

Извод нормы [`standards/workspace/layer-architecture.md`](../../../standards/workspace/layer-architecture.md)
для профиля `vue-spa`. Ядро говорит о направлении зависимостей; здесь названы
слои и способ объявления публичного входа — то, что вместе с каркасом
устаревает.

## 1. Порядок слоёв

Сверху вниз: `app`, `pages`, `widgets`, `features`, `entities`, `shared`.

Репозиторий вправе не иметь какого-то из слоёв. Отсутствие слоя порядок не
меняет: оставшиеся сохраняют взаимное положение.

## 2. Направление зависимости

Правило ядра §2 в именах этого профиля: `shared` не импортирует ничего из
`entities`, `features`, `widgets`, `pages`, `app`; `entities` импортирует
только `shared`, и так далее вверх.

## 3. Публичный вход

Публичный вход единицы — файл `index.ts` в её корне. Обращение между единицами
идёт только через него.

## 4. Внутри единицы

Внутри единицы — относительные пути, без обращения к собственному `index.ts`.
Это правило ядра §4 в именах профиля.

## 5. Что этот извод сузил относительно ядра

- назвал шесть слоёв и их порядок;
- назвал форму публичного входа (`index.ts`);
- назвал форму обращения внутри единицы (относительный путь).

Ничего к утверждениям ядра он не добавляет и ни одного не отменяет.
