# README writer standard

Use a README as the entry point for a repository, package or component. Start from `../templates/readme-template.md`. Explain purpose, prerequisites, verified commands and links to deeper documentation. Do not invent commands, configuration, or operational guarantees. README uses the lightweight visible status model (`maintained`, `stale`, `deprecated`, `archived`) from [the document status model](../workspace/document-status-model.md).

Render that visible status block bilingually as shown in the template; keep its machine identifier in English.

Keep implementation detail out of the README unless it is necessary to use the component.
